# MC 营销看板 (Marketing Dashboard)

MC 虚拟货币交易平台营销部门的独立看板网页。

## 📦 包含模块

- **营销物料库** — 文案 / 海报 / 落地页素材 12 条示例,支持按类型/语言/状态筛选
- **渠道 / 活动看板** — 10 个营销活动,6 种状态(进行中/排期/暂停/计划/结束/草稿)
- **营销 SOP** — 物料制作 / 多语言本地化 / KOL 合作 3 套 7 步标准作业流程
- **渠道总览** — 12 个付费/社媒/内容/私域渠道本月迄今数据

## 🌐 公网访问

本仓库已启用 **GitHub Pages**,发布后访问:

```
https://<你的 GitHub 用户名>.github.io/mc-marketing-dashboard/
```

iframe 友好 — 无 X-Frame-Options / CSP frame-ancestors 限制,可以直接被公司总台用 `<iframe>` 嵌入。

## 🛠 技术规格

- 单文件 HTML,所有 CSS / JS 内嵌(无外部依赖)
- 引用 Unsplash 公开图片(失败时自动降级为渐变 + 图标)
- 纯静态,任何静态托管商(GitHub Pages / Netlify / Vercel / S3)都可跑

## 📝 部署方式

本仓库使用 **GitHub Pages** 托管,`main` 分支根目录即为站点根。

如需更新:
1. 在网页上直接编辑 `index.html` 提交,或
2. 克隆到本地修改后 `git push`

## ⚠️ 当前状态:示例数据

物料链接、活动预算、负责人姓名等均为占位示例,**生产环境部署前**需要:
- 对接 DAM 素材库获取真实物料链接
- 对接 Asana / 内部活动管理系统获取活动数据
- 法务 / 合规复核(物料如涉及 ROI / 保本 / 收益承诺必走合规审核)

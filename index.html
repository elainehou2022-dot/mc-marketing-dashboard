营销 SOP（标准作业流程）

物料制作 · 多语言本地化 · KOL 合作 · 全流程合规与排期
FY26 v3.2

1 物料制作流程

从需求到上架 · 平均周期 5–7 个工作日
  1. 需求提报 · 业务/产品方在 Asana 提交 Brief（含目标受众、卖点、KPI）
  2. 创意策划 · 创意组输出 3 版 Concept，由市场负责人 review
  3. 文案撰写 · 中文母版 + 卖点对齐，合规初步审核
  4. 视觉设计 · 设计师出稿，符合品牌 VI Token
  5. 合规审核 · 法务 / 合规双签（涉及 ROI、保本、收益承诺必走）
  6. 上线发布 · 同步至 DAM 素材库 + 渠道投放后台
  7. 效果复盘 · 7 日、30 日表现数据回收
AsanaFigma合规 Checklist

2 多语言本地化流程

支持 6 种语言 · 母语级本地化 + 区域合规适配
  1. 源文锁定 · 中文 / 英文母版由市场+产品联合确认
  2. 机翻 + 术语库 · DeepL + 内部 Crypto/BiXin 术语库（1300+ 词条）
  3. 母语译者润色 · 签约译者交付（覆盖 繁中 / 简中 / EN / JA / KO / VI）
  4. 文化适配 · 替换本地梗、币种、支付方式、监管提示
  5. 合规复核 · 区域合规官复核（如日本 FSA、越南央行提示语）
  6. 双语 QA · 双语 PM 交叉检查关键术语、数字、链接
  7. 入库上线 · 落地页与广告同步切换语言版本
DeepLSmartling术语库 1300+

3 KOL 合作流程

筛选 → 签约 → 内容审核 → 上线 → 复盘
  1. 选号筛选 · 第三方数据（NoxInfluencer / HypeAuditor）筛查粉丝质量、互动率
  2. 分级入库 · S/A/B/C 分级，附粉丝画像与历史合作 ROI
  3. Brief 下发 · 标准化 Brief 包（含合规红线、必含卖点、可选角度）
  4. 内容审核 · 合规必审 8 项：无收益承诺 / 无拉踩 / 披露赞助 / 风险提示
  5. 上线监控 · 72h 内监控评论、私信、违规，引导至官方
  6. 效果归因 · UTM + 专属 promo code 回收 CPA / LTV
  7. 续约/下线 · 季度复盘进入下一轮筛选
NoxInfluencer合规 8 项UTM 追踪
🛡 合规红线速查（适用于上述所有流程）
· 禁止 任何「保本 / 稳赚 / 翻倍」收益承诺；
· 禁止 展示具体盈利用户案例（仅可展示策略/教学）；
· 必含 风险提示语（如「加密资产价格波动剧烈，可能损失全部本金」）；
· 受邀 KOL 必须在显著位置披露 赞助关系（#ad / #赞助）；
· 不同地区需附对应监管标识（香港 SFC、日本 FSA、欧洲 MiCA 等）。
